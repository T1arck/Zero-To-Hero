# InvestLab

Платформа для инвестирования в научные проекты и интеллектуальную собственность (ИС). Исследовательские команды публикуют проекты и дробят права на ИС на доли, а инвесторы покупают эти доли, получая совладение и право на долю от роялти.

## Возможности

### Для исследовательских команд
- Регистрация и профиль команды (название, описание, научная область).
- Публикация проектов: название, описание, тип актива ИС, процент роялти, сценарий монетизации.
- Дробление ИС на доли с указанием цены одной доли.
- Настройка **вех финансирования** (milestones) с процентами от собранной суммы.
- Закрытие вех — освобождение средств из эскроу.
- Публикация отчётов о прогрессе проекта для инвесторов.

### Для инвесторов
- Регистрация с автоматическим **стартовым балансом 10 000 ₽**.
- Каталог активных проектов с прогресс-барами и метриками.
- Покупка долей на первичном рынке (с проверкой баланса).
- **Вторичный рынок (P2P)**: выставление своих долей на продажу по своей цене и покупка лотов других инвесторов.
- Портфель долей с отображением отчётов команд по каждому проекту.

### Общее
- Аутентификация с "запомнить меня" (30 дней).
- CSRF-защита всех форм (`Flask-WTF`).
- Разграничение доступа по ролям (`role_required`).
- Адаптивный неоново-научный интерфейс (десктоп + мобильный).
- Идемпотентные миграции схемы БД при старте приложения.

## Технологический стек

| Слой | Технологии |
|---|---|
| Backend | Python 3.10+, Flask, Flask-Login, Flask-WTF, Flask-SQLAlchemy |
| ORM | SQLAlchemy (декларативные модели) |
| БД | SQLite (по умолчанию), легко заменяется на PostgreSQL |
| Frontend | Jinja2, HTML5, CSS3 (без фреймворков), ванильный JS |
| Безопасность | Werkzeug (хэширование паролей), CSRF-токены, проверка `next`-URL |

## Быстрый старт

### 1. Клонирование и виртуальное окружение

```bash
git clone <repo-url>
cd investlab

python -m venv .venv
source .venv/bin/activate      # Linux / macOS
# .venv\Scripts\activate       # Windows

### 2. Установка зависимостей

pip install -r requirements.txt

### 3. Запуск

python app.py
